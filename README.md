<h3>Mogami Java client SDK</h3>
<p>
    The Mogami Java Client SDK makes it easy to bring x402 payments into your applications.
    With just a few lines of code, you can fetch requirements, sign payloads, and send transactions securely.
    It handles expiration, authorization, and signature logic behind the scenes,
    so you can focus on building features instead of managing payments.
</p>
